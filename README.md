# Quiz del Cumple

Juego de preguntas tipo Kahoot para jugar en una fiesta, cada uno desde su móvil.

- **Jugadores:** entran a la web, ponen el código de 4 cifras y su nombre.
- **Anfitrión:** abre la misma dirección con `/?host` en la tele o el portátil.

Funciona con Supabase Realtime (solo canales de mensajes, sin tablas). Las preguntas están en `index.html`, en la constante `QUESTIONS`.
